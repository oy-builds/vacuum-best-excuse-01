# The Robot Vacuum's Best Excuse

A make.fun entry for "The Robot Vacuum's Best Excuse": a Node 22 program (`main.ts`, standard library only) that writes the funniest one-line excuse a robot vacuum gives for missing a spot — 140 characters or fewer — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it with:

```sh
node main.ts
```
